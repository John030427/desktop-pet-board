# Campus Muse Codex Pet

A burgundy-braided campus companion wearing a white-and-red jersey with **KOREA / UNIVERSITY** lettering.

## Files

- `pet.json` and `spritesheet.webp`: Codex desktop pet, sprite version 2 (1536 × 2288, 8 × 11 atlas).
- `web-upload.png`: transparent PNG prepared for the ChatGPT web pet uploader (1536 × 1872, 8 × 9 atlas).

## Use

For Codex desktop, extract the release archive so `pet.json` and `spritesheet.webp` sit together in a `campus-muse` folder under your Codex pets directory (on Windows: `%USERPROFILE%\.codex\pets\campus-muse\`).

For ChatGPT on the web, open **Settings → Personalization → Pets → Upload pet** and select `web-upload.png`. The desktop pet and web upload are separate formats and do not sync automatically.
